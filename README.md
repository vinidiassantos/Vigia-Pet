# 🐾 VIGIA PET

Monitoramento inteligente de pets usando visão computacional.

## 🚀 Funcionalidades
- 📷 Monitoramento via câmera do celular
- 🧠 Detecção de comportamentos (dormindo, comendo, agitado)
- 📊 Relatórios em tempo real
- 🔔 Notificações push
- ☁️ Sincronização com Firebase
- 📱 Suporte Android e Web

## 🛠️ Tecnologias
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Firebase (Firestore, Auth, Messaging)
- **IA:** TensorFlow Lite, MobileNetV2
- **Mobile:** Kotlin, Android Studio
